# Consul Simulator · Entrevista de visa B1/B2

App de práctica por AutoRise Solutions. Herramienta no oficial: no es del gobierno de EUA ni de ningún consulado y no garantiza la visa. Los datos (y la DS-160 que se cargue) se procesan y guardan solo en el dispositivo de cada persona.

App: https://jonmendozainv2021-code.github.io/simulador-visa/

Incluye pdf.js (Mozilla, licencia Apache 2.0) en `vendor/pdfjs/`.
